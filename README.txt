المالك الرئيسي: سامح حماده

تشغيل السيرفر:
  1) npm install
  2) ADMIN_KEY=كلمة_سر_قوية npm start
  3) افتح http://localhost:3000

لوحة الشحن: افتح /admin وادخل بمفتاح الأدمن، اكتب ID اللاعب وعدد النقاط واضغط شحن.

متغيرات البيئة (Environment):
  ADMIN_KEY       مفتاح لوحة الأدمن (لازم تضبطه، لو مش مضبوط بيطلع مفتاح مؤقت في اللوج)
  DATA_DIR        مكان حفظ data.json (حسابات اللاعبين والنقاط). على Render لازم Persistent Disk
                  وإلا الحسابات والنقاط بتتمسح مع كل إعادة تشغيل.
  WELCOME_POINTS  نقاط هدية للاعب الجديد (الافتراضي 10)

إضافة ماتشات: عدّل ملف matches.json (نفس شكل الماتشات الموجودة).
